# Deal or No Deal

A Windows desktop application recreating the Deal or No Deal game show built to practice C# and Windows Presentation Foundation (WPF).

### Features

- Built using C# and XAML
- Event-driven game loop managing user selections
- Tracks opened boxes and calculates dynamic Banker offers
- Multi-window navigation between rules and the active game board

### Tech Stack

- C#
- .NET
- WPF
- Visual Studio

### Running the Application

- Clone the repository
- Open `Deal or No Deal.sln` in Visual Studio
- Ensure .NET desktop development workloads are installed
- Build and run the project
